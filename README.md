# Avance 1 — Chatbot de publicidad (prototipo académico)

**Alcance:** chatbot basado en reglas para capturar categoría (MANGAS, DC, MARVEL, OTROS) y precio; confirmar, corregir, cancelar y pedir ayuda. No clasifica portadas ni genera imágenes.

## Ejecución local (Python 3.10+)

```bash
python -m pip install -r requirements.txt
python chatbot.py
```
